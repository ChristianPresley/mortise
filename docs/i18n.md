# Languages

A site can be written in several languages. List them in `_config.yml`,
each code with the language's own name:

```yaml
languages:
  en: English
  fr: Français
default_language: en   # optional; the first language otherwise
```

## Translating pages

A page's language comes from its path:

| Source                      | Language | URL                      |
| --------------------------- | -------- | ------------------------ |
| `about.md`                  | default  | `/about/`                |
| `about.fr.md`               | French   | `/fr/about/`             |
| `fr/guide.md`               | French   | `/fr/guide/`             |
| `_posts/2024-03-01-hi.fr.md`| French   | `/fr/2024/03/01/hi/`     |
| `index.fr.md`               | French   | `/fr/` (its home page)   |

Pages whose paths are the same apart from the language are translations
of each other: `about.md`, `about.fr.md` and `fr/about.md` are one page in
two languages. A page does not need a translation. Default-language pages
live at the root, and a `permalink:` is used exactly as written.

## In templates

Every template sees the current page's language:

| Variable            | Value                                                        |
| ------------------- | ------------------------------------------------------------ |
| `page.lang`         | The page's language code                                     |
| `page.translations` | The page in other languages, each `{code, name, url}`        |
| `site.lang`         | The language of the page being rendered                      |
| `site.languages`    | Every language, default first, each `{code, name, url}` with the URL of its home page |
| `site.i18n`         | The strings in `_data/i18n/CODE.yml` for the current language |

`site.posts`, `site.pages`, `site.nav` and `site.tags` hold only the
current language's pages, and `page.previous`, `page.next` and pagination
stay within it, so the same templates serve every language.

```html
<html lang="{{ site.lang }}">
{% for t in page.translations %}<link rel="alternate" hreflang="{{ t.code }}" href="{{ t.url }}">{% endfor %}

<nav>{% for l in site.languages %}<a href="{{ l.url }}" lang="{{ l.code }}">{{ l.name }}</a>{% endfor %}</nav>

<h2>{{ site.i18n.latest_posts }}</h2>
```

with `_data/i18n/en.yml` holding `latest_posts: Latest posts` and
`_data/i18n/fr.yml` holding `latest_posts: Derniers articles`.

## Generated pages

- Each language with posts gets its own Atom feed: `feed.xml` for the
  default language, `fr/feed.xml` for French.
- Tag pages (`_layouts/tag.html`) are made per language, at `/tags/NAME/`
  and `/fr/tags/NAME/`.
- The sitemap lists every page in every language.

[`examples/i18n/`](../examples/i18n) is a small site in English and
French with a language switcher.
