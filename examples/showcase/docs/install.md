# Install

:::steps
1. Install Zig 0.16.0 from [ziglang.org](https://ziglang.org/download/).
2. Clone Mortise and run `zig build -Doptimize=ReleaseFast`.
3. Put `zig-out/bin/mortise` on your `PATH`.
:::

> [!TIP]
> `mortise new my-site` writes a starter site to begin from.
