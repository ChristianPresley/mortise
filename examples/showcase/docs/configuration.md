# Configuration

Settings live in `_config.yml` and are available to templates as `site.*`.

title
: The site's name.

url
: The absolute address. Turns on `feed.xml` and `sitemap.xml`.

baseurl
: A path prefix such as `/blog` when the site does not live at the root.

components_css
: Set to `false` to skip writing `mortise.css`.
