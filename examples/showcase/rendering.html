Rendered graphics

Everything on this page was drawn by Mortise while building the site, from the small spec files in _render/images/rendered/. There are no image files in the source tree and no JavaScript.

hud-panel.yml renders a panel frame and hud-panel.css, which uses it as a CSS border image. The box stretches to fit whatever is inside.

stars.yml: a starfield that tiles seamlessly.

Social cards

card specs draw 1200×630 link-preview images with the built-in stroke font, in three styles: plain, visor and lcars.

Site icons

icons: in _config.yml draws the favicon, the app icons and a web manifest in the theme's style.
